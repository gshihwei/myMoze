# 帳小簿銀行同步（電腦程式）

在你自己的 Windows 電腦上登入銀行，讀取**最近三個月的明細和帳戶餘額**，寫進你的帳小簿雲端資料。
手機或電腦上的帳小簿打開「更多 → 銀行同步」就看得到，可以自動對應已記的帳、一鍵記帳、比對餘額。

目前支援：**玉山銀行**（存款、信用卡）、**中國信託**（臺幣存款、信用卡）。

## 運作方式與安全

```
你的電腦（這支程式）──登入──> 銀行
        │
        └─ 只寫入你自己的帳小簿雲端資料（Supabase，和 App 同一個帳號、同一套權限）
```

- **銀行帳密只存在這台電腦**，用 Windows 內建的 DPAPI 加密（綁定你的 Windows 帳號），放在 `%APPDATA%\zhangxiaobu-bank\`，不在程式資料夾裡，也不會上傳。
- **帳小簿雲端密碼不會存下來**：只在 `login` 時用一次，之後用登入憑證（同樣加密存放）。
- 寫到雲端的只有日期、金額、說明和**帳號末四碼**。說明裡的長串數字（例如轉帳帳號）只留末四碼；銀行回傳的原始資料不保存。
- 玉山用一個**獨立、用完即刪**的 Edge 視窗登入，不會碰到你平常用的 Edge、書籤和登入狀態。
- 任何能以你的 Windows 帳號執行程式的人，都能解開這些加密資料。請替 Windows 帳號設密碼，不要在共用電腦上使用。

## 安裝

1. 安裝 [Node.js](https://nodejs.org/) 22.12 以上。
2. 在這個資料夾（`bank-agent`）開啟命令提示字元或 PowerShell，執行：

   ```
   npm install
   ```

3. 第一次設定（依提示操作）：

   ```
   node cli.mjs setup
   ```

   會依序：
   - 登入帳小簿雲端（跟 App「設定 → 雲端同步」同一個帳號）
   - 選擇要設定的銀行，輸入身分證字號、使用者名稱／代號、網銀密碼（輸入時不會顯示）
   - 立刻同步一次

4. 設定每天自動同步（電腦當時沒開機，下次開機後會補跑）：

   ```
   node cli.mjs schedule 07:30
   ```

   要一天兩次可以寫 `node cli.mjs schedule 07:30 19:30`。

## 在帳小簿裡使用

打開「更多 → 銀行同步」：

1. **對應帳戶**：每個銀行帳戶旁選擇對應的帳小簿帳戶，或選「建立新帳戶」（用銀行目前餘額建立，從明天起的明細才需要記帳）。
2. **待處理**：同一個帳戶、金額相同、前後 3 天內只有一筆的記錄會**自動對應**；其他明細可以按「記帳」（帶入日期、金額、帳戶，猜類別）、「連結」到已記的帳，或「略過」。
3. **餘額比對**：每個帳戶顯示銀行餘額和帳小簿餘額，不一致時會標出差多少。
4. 同步失敗或需要你處理時，通知中心會提醒。

## 常用指令

| 指令 | 用途 |
|---|---|
| `node cli.mjs sync` | 現在同步全部銀行 |
| `node cli.mjs sync esun` | 只同步玉山（`ctbc` 是中信） |
| `node cli.mjs sync esun --show` | 顯示瀏覽器畫面，方便看卡在哪裡 |
| `node cli.mjs add ctbc` | 新增或更新中信的帳密（密碼改了要執行） |
| `node cli.mjs remove esun` | 刪除玉山的帳密 |
| `node cli.mjs status` | 查看設定、上次同步結果、自動同步時間 |
| `node cli.mjs unschedule` | 取消每天自動同步 |

同步紀錄在 `%APPDATA%\zhangxiaobu-bank\sync.log`（不含密碼和明細內容）。

## 需要你處理的情況

- **中信要求在 App 核准或輸入 Email 驗證碼**：自動同步會停下，App 的「銀行同步」與通知中心會顯示原因。請在電腦上手動執行 `node cli.mjs sync ctbc`，依提示在中信 App 按核准（或輸入 e 改用 Email 驗證碼）。
- **銀行要求變更密碼、裝置綁定或其他額外驗證**：先用官方 App 或網銀處理，再執行 `node cli.mjs add <銀行>` 更新密碼。
- **自動登入可能讓你正在使用的網銀或銀行 App 被登出**，這是銀行的單一登入限制。

## 限制

- 這不是銀行提供的正式 API，而是模擬網銀頁面／App 的操作；**銀行改版時可能失效**，需要更新程式。
- 大部分銀行的條款不允許程式自動登入，可能被要求重設密碼或暫停網路銀行，請自行評估。
- 只讀取，不會轉帳或變更任何銀行設定。
- 中信目前不含外幣存款和貸款；玉山所有信用卡合併成一個帳戶（銀行的帳單是合併的）。
