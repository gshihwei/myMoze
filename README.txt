帳小簿 V26.7（原 MOZE PWA）

本版本新增完整「借還款」頁面：
- 應收／應付／已完成分頁
- 依對象分組
- 新增借出／借入
- 部分收款／還款與全額收還
- 收還款歷史
- 停止追蹤
- 借還款會調整實際帳戶餘額，但不列入一般支出／收入

部署：維持 V25.x 的靜態 PWA + Supabase 架構。

V25.8：CSV 匯入的應收款項／應付款項會直接建立借還款資料與收還款歷史，匯入後可在「借還款」頁面追蹤。

V25.9：CSV 借還款配對修正（方向、停止追蹤、幣別）、同名不同幣別帳戶分開、收還款手續費／折扣、追加匯入可選擇套用到既有帳戶餘額。

V25.10：雲端同步新增「忘記密碼」與「變更密碼」；修正雲端已無資料時同步衝突按鈕沒有反應。

V25.10.1：密碼欄位加上眼睛圖示，可切換顯示／隱藏密碼。

V25.11：app.bundle.js 改由 tools/build-bundle.js 從 app.js 產生（修改 js/app.js、js/icons.js、js/entry-ui.js 後必須執行 node tools/build-bundle.js）；補回 V25.6 起遺漏的餘額修正；借還款交易不可從交易明細編輯／刪除。
V25.12：雲端同步面板顯示「最後成功同步」時間、上傳／下載筆數與待上傳筆數；頂部狀態顯示「已同步 HH:MM」；同步進行中產生的新變更會在完成後自動再同步一次。
V25.13：設定 → 資料 新增「帳戶對帳」：逐帳戶檢查 目前餘額 = 初始金額 + 交易合計；可選原始 MOZE CSV 讀取初始金額自動比對，並一鍵修正差額（修正前自動下載 JSON 備份）。
V25.14：安全性修正：帳戶、分類、交易、商家、備註、借還款對象等文字顯示前一律跳脫 HTML 特殊字元，CSV 或雲端資料中的 < > " & 不會被當成網頁程式碼執行。
V25.15：有新版本時畫面下方出現「MOZE 已更新到 Vx.x，立即更新」提示，不必再關閉 App 重開；App 回到前景時與每 30 分鐘自動檢查新版本。
V25.16：外幣帳戶在下拉選單、帳戶頁與帳戶明細顯示為「名稱（USD）」，餘額以帳戶本身幣別顯示；淨資產只加總 TWD 帳戶，外幣另列（未換算）。
V25.17：新裝置不再產生示範資料（只有預設分類與兩個 0 元帳戶），登入有資料的帳號時自動採用雲端資料；同步衝突可「全部保留雲端／全部保留本機」；「清除所有資料」會先備份並在已登入時二次確認。
V25.18：帳戶對帳不再需要原始 MOZE CSV：可在每個帳戶直接輸入記得的初始金額，或按「未填的以 0 比對」；手動輸入會記在這台裝置。
V25.19：借還款可刪除單筆收還款、刪除整筆借還款（相關交易一併刪除並還原帳戶餘額）、恢復追蹤，以及編輯對象／名稱／到期日／備註。
V25.20：淨資產自動把外幣帳戶換算成新台幣（匯率每 12 小時從 open.er-api.com 更新，失敗時改用 jsDelivr currency-api；離線使用上次的匯率）。
V25.21：CSV 有錯誤列時明確標示為「部分匯入」、列出受影響帳戶，須勾選確認才能匯入；可下載錯誤列 CSV 修正後追加匯入。
V26.0：App 改名為「帳小簿」（仍相容 MOZE CSV 匯入）；概覽三卡顯示與上月比較的百分比；收支圖表改為 SVG，依所選月份顯示近 6／12 個月的支出、收入長條與月底淨資產折線，可點選月份查看明細；分析頁新增 12 個月淨資產走勢。
V26.1：日曆格子顯示當日淨額、週末標色；右側「月統計」與「當日明細」（時間、#標籤、商家、專案與帳戶標籤）；記帳表單新增時間與標籤；交易明細可搜尋標籤；修正編輯匯入交易會遺失時間、幣別、手續費與匯入 key。
V26.2：週期交易支援頻率／間隔／結束條件、編輯刪除、入帳與略過；概覽「即將到來」列出 30 天內到期的週期交易；新的待完成交易確認入帳前不計入餘額，概覽可確認入帳或刪除。
V26.3：概覽改為兩欄（信用卡帳單、待完成交易、借還款追蹤／即將到來）；信用卡帳單顯示狀態、到期日與未繳金額；借還款依對象分組；手機版頂部可切換月份；修正 CSV 匯入的信用卡繳款不會算進帳單。
V26.4：報表分析頁（期間／收支／帳戶篩選、KPI 與上期比較、分類排行可下鑽子分類、每日／每月收支、淨資產走勢、商家／標籤／帳戶／專案排行、表格檢視）；手機版底部改為「概覽、交易、＋、分析、更多」，可進入所有功能；圖表依實際寬度繪製、單一座標軸。原始碼新增 js/analysis.js（併入 app.bundle.js）。
V26.4.1：修正概覽圖表刻度之間多出來的格線（舊版長條圖遺留的背景格線）。
V26.5：介面字體改為 Google Fonts「Huninn」（粉圓，SIL OFL），字型檔由 service worker 快取，離線仍可顯示。
V26.6：預算改版——可設每月總支出、分類（含子分類）或專案預算，可編輯刪除；卡片顯示已用／上限、剩餘、每日可用、今日進度與狀態；概覽新增「本月預算」。原始碼新增 js/budgets.js（併入 app.bundle.js）。
V26.7：分類管理——支出／收入分頁、子分類、編輯名稱與圖示、上下排序；刪除使用中的分類時可指定改用的分類（交易、拆帳、週期、預算一併改）。原始碼新增 js/categories.js。
