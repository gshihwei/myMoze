帳小簿 V26.85（原 MOZE PWA）

本版本新增完整「借還款」頁面：
- 應收／應付／已完成分頁
- 依對象分組
- 新增借出／借入
- 部分收款／還款與全額收還
- 收還款歷史
- 停止追蹤
- 借還款會調整實際帳戶餘額，但不列入一般支出／收入

部署：維持 V25.x 的靜態 PWA + Supabase 架構。

V25.8：CSV 匯入的應收款項／應付款項會直接建立借還款資料與收還款歷史，匯入後可在「借還款」頁面追蹤。

V25.9：CSV 借還款配對修正（方向、停止追蹤、幣別）、同名不同幣別帳戶分開、收還款手續費／折扣、追加匯入可選擇套用到既有帳戶餘額。

V25.10：雲端同步新增「忘記密碼」與「變更密碼」；修正雲端已無資料時同步衝突按鈕沒有反應。

V25.10.1：密碼欄位加上眼睛圖示，可切換顯示／隱藏密碼。

V25.11：app.bundle.js 改由 tools/build-bundle.js 從 app.js 產生（修改 js/app.js、js/icons.js、js/entry-ui.js 後必須執行 node tools/build-bundle.js）；補回 V25.6 起遺漏的餘額修正；借還款交易不可從交易明細編輯／刪除。
V25.12：雲端同步面板顯示「最後成功同步」時間、上傳／下載筆數與待上傳筆數；頂部狀態顯示「已同步 HH:MM」；同步進行中產生的新變更會在完成後自動再同步一次。
V25.13：設定 → 資料 新增「帳戶對帳」：逐帳戶檢查 目前餘額 = 初始金額 + 交易合計；可選原始 MOZE CSV 讀取初始金額自動比對，並一鍵修正差額（修正前自動下載 JSON 備份）。
